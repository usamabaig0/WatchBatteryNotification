# Wear Battery — DESIGN.md

## 1. Design System Overview

### Product personality
Wear Battery is a premium, professional battery-monitoring utility for Android phones and Wear OS devices.
The visual identity should feel: Professional, Calm, Reliable, Modern, Premium, Intelligent, Accessible, Technically capable, Easy to understand.

### Core design statement
> Professional first. Modern second. Futuristic only through subtle details.
Information is the visual interest. Decoration stays subtle.

## 2. Design Principles
1. Clarity before decoration
2. Semantic color
3. Hierarchy creates emphasis
4. Familiar Android interaction
5. Calm telemetry
6. Subtle technology
7. Accessible by default
